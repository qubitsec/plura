# 현대로템 PLURA-XDR PoC 구성 선택안

## 1. 제안 배경

현대로템의 온프레미스 환경은 외부 인터넷 노출과 공격 트래픽이 제한되어 있어, PoC 기간 중 실제 외부 공격 이벤트가 충분히 발생하지 않을 가능성이 있습니다.

따라서 온프레미스 환경에서는 서버·PC의 감사정책 수립과 통제된 모의 행위를 중심으로 PLURA-XDR의 탐지 역량을 검증합니다.

미토스급 AI 해킹 공격에 대한 대응 역량은 운영환경과 분리된 퍼블릭 클라우드에 격리형 PoC 환경을 구성하고, 실제와 유사한 공격을 시연하는 방식으로 검증합니다.

각 선택안은 하나만 선택하는 방식으로 제한하지 않으며, 현대로템의 검증 목적에 따라 다음과 같이 조합할 수 있습니다.

* **선택안 1 단독**
* **선택안 2 단독**
* **선택안 3 단독**
* **선택안 1 + 선택안 3**
* **선택안 2 + 선택안 3**

---

## 2. PoC 환경 및 구성 선택안

### 선택안 1. 온프레미스 제한환경 — EDR 전용

외부 인터넷 노출과 실제 공격 트래픽이 제한된 온프레미스 환경을 대상으로 합니다.

실제 외부 공격 이벤트가 충분히 발생하지 않을 수 있으므로, 서버와 PC의 감사정책을 수립하고 통제된 모의 행위를 발생시켜 PLURA-XDR의 호스트 기반 탐지 역량을 검증합니다.

#### 주요 범위

* Windows·Linux 서버 및 업무용 PC 감사정책 수립
* 명령어·프로세스·파일·계정·네트워크 이벤트 수집
* MITRE ATT&CK 기반 침해 행위 분석
* PowerShell·LOLBAS·LOTL 등 정상 시스템 도구 악용 탐지
* 권한 상승과 계정·권한 변경 탐지
* 비정상 명령 및 스크립트 실행 탐지
* 내부 호스트·서비스 탐색 행위 분석
* 주요 탐지 이벤트에 대한 자동 포렌식과 증거 확인

#### 핵심 검증

> 서버와 PC에서 발생하는 감사 로그를 기반으로 정상 운영 행위와 침해 의심 행위를 구분하고,  
> MITRE ATT&CK 관점에서 탐지·분석할 수 있는지를 확인합니다.

---

### 선택안 2. 온프레미스 제한환경 — WAF + EDR

서버와 PC의 호스트 보안뿐 아니라, 현대로템 내부에서 운영하는 웹서버와 웹 애플리케이션까지 함께 보호하는 구성입니다.

온프레미스 제한환경에서는 실제 외부 공격보다 통제된 웹 공격을 수행하고, 웹 요청과 서버 내부 행위를 연결하여 분석하는 데 중점을 둡니다.

#### 주요 범위

* Windows·Linux 서버 및 업무용 PC 감사정책 수립
* MITRE ATT&CK 기반 침해 행위 분석
* 내부 웹서버와 웹 애플리케이션 보호
* SQL 인젝션, 명령어 삽입, 파일 업로드 등 웹 공격 탐지
* 웹 요청 이후 발생하는 명령·프로세스·파일 이벤트 분석
* 웹 공격과 서버 내부 침해 행위의 연계 분석
* PLURA-WAF 공격 탐지·차단
* PLURA-EDR 기반 호스트 행위 분석과 자동 포렌식
* WAF와 EDR 이벤트의 PLURA-XDR 통합 분석

#### 적용 전 확인사항

* 보호 대상 내부 웹서버의 위치와 수량
* 웹 트래픽의 PLURA-WAF 경유 또는 연동 가능 여부
* HTTPS 복호화 및 요청·응답 분석 가능 범위
* 통제된 웹 공격 테스트 수행 가능 여부
* 운영서비스 영향 없이 테스트할 수 있는 대상 시스템 확보 여부

#### 핵심 검증

> 내부 웹서비스에서 발생한 공격 요청과 서버 내부의 후속 행위를 연결하여,  
> 웹 공격부터 호스트 침해까지 통합적으로 탐지할 수 있는지를 확인합니다.

---

### 선택안 3. 퍼블릭 클라우드 개방형 PoC 환경 — WAF + EDR

퍼블릭 클라우드에 인터넷으로 접근할 수 있는 격리형 PoC 환경을 구축하고, 실제와 유사한 해킹 공격을 시연하는 구성입니다.

미토스급 AI가 외부 공격 표면과 취약점을 탐색하고, 공격 코드를 생성·변형하여 웹서버 침투를 시도하는 상황을 재현합니다.

#### 주요 범위

* 인터넷에 노출된 격리형 웹서비스 구축
* 미토스급 AI 기반 공격 표면과 취약점 탐색 시연
* AI가 생성하거나 변형한 웹 공격 시연
* 기존 WAF 정책을 우회하는 변형·제로데이 의심 공격 검증
* PLURA-WAF를 통한 웹 공격 탐지와 차단
* 웹서버 최초 명령 실행 탐지
* 웹셸 및 악성파일 생성 탐지
* OS·버전·패치·설치 소프트웨어·보안제품 탐색 행위 분석
* MITRE ATT&CK 기반 권한 상승과 내부 이동 탐지
* LOLBAS·LOTL 기반 정상 시스템 도구 악용 탐지
* 중요 데이터 수집·압축과 승인된 모의 유출 탐지
* 웹 요청부터 서버 침해와 데이터 유출까지 전체 공격 체인 분석
* PLURA-XDR 기반 차단·알림·자동 포렌식 대응

#### 핵심 검증

> 미토스급 AI가 생성한 변형·제로데이 의심 공격에 대해 PLURA-XDR이 웹 요청과 서버·PC 행위를 연결하여 탐지하고,  
> PLURA-WAF와 PLURA-EDR을 통해 차단·분석·포렌식할 수 있는지를 확인합니다.

## 3. 선택안 조합

### 조합안 A. 선택안 1 + 선택안 3

현대로템 온프레미스 환경에는 PLURA-EDR을 적용하고, 퍼블릭 클라우드에는 PLURA-WAF와 PLURA-EDR을 적용하는 구성입니다.

#### 온프레미스 검증

* 서버·PC 감사정책 수립
* MITRE ATT&CK 기반 호스트 침해 행위 분석
* PowerShell·LOLBAS·LOTL 탐지
* 권한 상승, 계정 변경, 내부 탐색과 비정상 명령 실행 탐지
* 자동 포렌식과 침해 증거 확인

#### 퍼블릭 클라우드 검증

* 미토스급 AI 해킹 공격 시연
* AI 변형·제로데이 의심 웹 공격 탐지
* PLURA-WAF 탐지·차단
* 최초 침투 이후 서버 내부 행위 분석
* 데이터 수집·모의 유출 탐지
* 전체 공격 체인 분석과 포렌식

#### 조합 목적

> 실제 온프레미스 환경에서는 EDR 적용 가능성과 호스트 탐지 역량을 검증하고,  
> 퍼블릭 클라우드에서는 미토스급 AI 공격에 대한 PLURA-XDR의 전체 대응 역량을 시연합니다.

---

### 조합안 B. 선택안 2 + 선택안 3

현대로템 온프레미스 환경과 퍼블릭 클라우드 환경 모두에 PLURA-WAF와 PLURA-EDR을 적용하는 구성입니다.

#### 온프레미스 검증

* 서버·PC 감사정책 수립
* MITRE ATT&CK 기반 호스트 침해 행위 분석
* 내부 웹서버와 웹 애플리케이션 보호
* 통제된 웹 공격 탐지·차단
* 웹 요청과 서버 내부 행위의 연계 분석
* WAF·EDR 통합 탐지와 자동 포렌식

#### 퍼블릭 클라우드 검증

* 미토스급 AI 해킹 공격 시연
* 외부 공격 표면과 취약점 탐색
* AI 변형·제로데이 의심 공격 탐지
* 웹 침투 이후 Discovery·권한 상승·내부 이동 탐지
* 데이터 수집·압축·모의 유출 탐지
* 최초 공격부터 대응·포렌식까지 전체 공격 체인 검증

#### 조합 목적

> 현대로템 내부 웹서비스와 서버·PC에 대한 WAF·EDR 통합 적용 가능성을 검증하고,  
> 퍼블릭 클라우드에서는 미토스급 AI 공격에 대한 PLURA-XDR의 차별화된 대응 역량을 함께 시연합니다.

## 6. 제안 방향

현대로템의 PoC는 단일 선택안뿐 아니라, 온프레미스 환경 검증과 퍼블릭 클라우드 공격 시연을 결합하여 구성할 수 있습니다.

현대로템의 실제 온프레미스 서버와 PC에 대한 적용 가능성을 우선 확인하는 경우에는 **선택안 1**을 적용합니다.

내부 웹서버 보호와 서버·PC의 통합 보안까지 확인하는 경우에는 **선택안 2**를 적용합니다.

미토스급 AI 해킹 공격에 대한 PLURA-XDR의 차별성과 전체 대응 역량을 직접 시연하는 경우에는 운영환경과 분리된 퍼블릭 클라우드에 격리형 PoC 환경을 구성하는 **선택안 3**을 적용합니다.

보다 종합적인 검증을 위해서는 다음 조합을 제안합니다.

* **선택안 1 + 선택안 3**

  * 온프레미스 서버·PC에 대한 EDR 적용 가능성 검증
  * 퍼블릭 클라우드에서 미토스급 AI 공격 대응 시연

* **선택안 2 + 선택안 3**

  * 온프레미스 서버·PC와 내부 웹서버에 대한 WAF·EDR 통합 검증
  * 퍼블릭 클라우드에서 미토스급 AI 공격 대응 시연

온프레미스 내부 웹서버를 보호 대상에 포함하지 않는 경우에는 **선택안 1 + 선택안 3**이 적합합니다.

온프레미스 내부 웹서버까지 PLURA-XDR의 보호 범위에 포함하는 경우에는 **선택안 2 + 선택안 3**이 적합합니다.

따라서 다음 순서로 PoC 범위를 확정합니다.

> ① 온프레미스 보호 대상을 서버·PC로 한정할지, 내부 웹서버까지 포함할지 결정  
> → ② 온프레미스 구성을 EDR 또는 WAF+EDR로 선택  
> → ③ 퍼블릭 클라우드 미토스급 AI 공격 시연 병행 여부 결정  
> → ④ 보호 대상 서버·PC·웹서비스와 수량 확정  
> → ⑤ 감사정책과 수집 대상 로그 범위 확정  
> → ⑥ 공격 시연 항목과 허용 범위 확정  
> → ⑦ 세부 PoC 시나리오와 성공 기준 수립
