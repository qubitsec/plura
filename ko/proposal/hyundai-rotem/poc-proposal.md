## PoC 환경 및 구성 선택안

현대로템의 운영 환경과 PoC 목적에 따라 다음 세 가지 구성 중 하나를 우선 선택합니다.

### 선택안 1. 온프레미스 제한환경 — EDR 전용

외부 인터넷 노출과 실제 공격 트래픽이 제한된 온프레미스 환경을 대상으로 합니다.

실제 외부 공격 이벤트가 충분히 발생하지 않을 수 있으므로, 서버와 PC의 감사정책을 수립하고 통제된 모의 행위를 발생시켜 PLURA-XDR의 호스트 기반 탐지 역량을 검증합니다.

#### 주요 범위

* Windows·Linux 서버 및 업무용 PC 감사정책 수립
* 명령어·프로세스·파일·계정·네트워크 이벤트 수집
* MITRE ATT&CK 기반 침해 행위 분석
* PowerShell·LOLBAS·LOTL 등 정상 시스템 도구 악용 탐지
* 권한 상승, 계정 변경 및 비정상 명령 실행 탐지
* 주요 탐지 이벤트에 대한 자동 포렌식과 증거 확인

#### 핵심 검증

> 서버와 PC에서 발생하는 감사 로그를 기반으로 정상 운영 행위와 침해 의심 행위를 구분하고, MITRE ATT&CK 관점에서 분석할 수 있는지를 확인합니다.

---

### 선택안 2. 온프레미스 제한환경 — WAF + EDR

서버와 PC의 호스트 보안뿐 아니라, 현대로템 내부에서 운영하는 웹서버와 웹 애플리케이션까지 함께 보호하는 구성입니다.

외부 공격 시연보다는 내부 웹서비스에서 발생하는 웹 요청과 서버 행위를 연결하여 분석하는 데 중점을 둡니다.

#### 주요 범위

* 서버 및 PC 감사정책 수립
* MITRE ATT&CK 기반 침해 행위 분석
* 내부 웹서버와 웹 애플리케이션 보호
* SQL 인젝션, 명령어 삽입, 파일 업로드 등 웹 공격 탐지
* 웹 요청 이후 발생하는 명령·프로세스·파일 이벤트 연계
* 웹 공격과 서버 침해 행위의 통합 분석
* PLURA-WAF 차단과 PLURA-EDR 포렌식 연계

#### 적용 전 확인사항

* 보호 대상 내부 웹서버의 위치와 수량
* 웹 트래픽의 PLURA-WAF 경유 또는 연동 가능 여부
* HTTPS 복호화와 요청·응답 분석 가능 범위
* 통제된 웹 공격 테스트 수행 가능 여부

#### 핵심 검증

> 내부 웹서비스에서 발생한 공격 요청과 서버 내부의 후속 행위를 연결하여, 웹 공격부터 호스트 침해까지 통합적으로 탐지할 수 있는지를 확인합니다.

---

### 선택안 3. 퍼블릭 클라우드 개방형 PoC 환경 — WAF + EDR

퍼블릭 클라우드에 인터넷으로 접근할 수 있는 격리된 PoC 환경을 구축하고, 실제와 유사한 해킹 공격을 시연하는 구성입니다.

미토스급 AI가 외부 공격 표면과 취약점을 탐색하고, 변형 공격을 생성하여 웹서버 침투를 시도하는 상황을 재현합니다.

#### 주요 범위

* 인터넷에 노출된 격리형 웹서비스 구축
* 미토스급 AI 기반 공격 표면·취약점 탐색 시연
* AI가 생성하거나 변형한 웹 공격 시연
* PLURA-WAF를 통한 웹 공격 탐지와 차단
* 웹서버 최초 명령 실행과 웹셸·악성파일 생성 탐지
* OS·버전·패치·소프트웨어·보안제품 탐색 행위 분석
* MITRE ATT&CK 기반 권한 상승과 내부 이동 탐지
* 중요 데이터 수집·압축·모의 유출 탐지
* 웹 요청부터 서버 침해까지 전체 공격 체인 분석
* PLURA-XDR의 차단·알림·자동 포렌식 대응

#### 핵심 검증

> 미토스급 AI가 생성한 변형·제로데이 의심 공격에 대해 PLURA-XDR이 웹 요청과 서버·PC 행위를 연결하여 탐지하고, PLURA-WAF와 PLURA-EDR을 통해 차단·분석·포렌식할 수 있는지를 확인합니다.

## 권고 방향

현대로템의 실제 온프레미스 환경에 대한 제품 적용 가능성을 우선 확인하려면 **선택안 1 또는 선택안 2**가 적합합니다.

미토스급 AI 해킹 공격에 대한 PLURA-XDR의 차별성과 전체 대응 역량을 직접 시연하려면, 운영환경과 분리된 퍼블릭 클라우드에 격리형 PoC 환경을 구성하는 **선택안 3**을 권고합니다.

따라서 다음 순서로 PoC 범위를 확정합니다.

> ① 온프레미스 또는 퍼블릭 클라우드 환경 선택
> → ② EDR 또는 WAF+EDR 구성 선택
> → ③ 보호 대상 서버·PC·웹서비스 확정
> → ④ 공격 시연 허용 범위 확정
> → ⑤ 세부 PoC 시나리오와 성공 기준 수립
